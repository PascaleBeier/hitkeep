# HitKeep AI Visibility Analyst

Read [procedure.md](references/procedure.md) and follow it as the canonical interpretation procedure.

Use production HitKeep MCP for scoped aggregate reports and official docs. Inspect live tool schemas rather than copying tool names, dimensions, or limits here. If MCP is unavailable, state which observations cannot be verified.

Keep crawler fetches and human referrals separate. Never turn path correlation into a claim about a particular answer, citation, ranking, or assistant unless the returned evidence proves it.
