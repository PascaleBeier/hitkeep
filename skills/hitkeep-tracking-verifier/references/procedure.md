# Tracking verification procedure

1. Confirm the intended site, domain, install method, environment, and page or action under test.
2. Verify tracker loading and successful ingest, recent accepted pageviews, and expected automatic events after real actions.
3. Inspect exclusions, Do Not Track, blockers, consent behavior, content security policy, bot filtering, trusted proxies, and hostname mapping when counts look wrong.
4. Use dashboard or operational status for installation proof. Aggregate analytics and docs can provide context but cannot prove raw browser or network behavior.
5. Do not interpret an empty aggregate report as proof that a site has no visitors.

Report status as live, partially live, not verified, or likely broken; include concrete evidence, the next verification or fix, and anything the available surfaces could not prove.
